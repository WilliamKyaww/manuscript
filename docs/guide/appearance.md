# Appearance

**Settings → Appearance** changes how Manuscript looks, never what it can do or what is in your vault. Each choice
applies at once and is remembered on this computer (the desktop app and a browser each keep their own).

## Theme

**Light**, **Dark** or **Match system** (follows the Windows setting, and changes with it).

## Palette

The colours of surfaces, text and the accent (links, buttons, the selected note, focus), in both themes:

| Palette | Surfaces | Accent |
|---|---|---|
| **Manuscript** (the default) | Warm paper | Forest green |
| **Graphite** | True neutral greys — the closest to Obsidian | Ink blue |
| **Sand** | Warmer, softer paper | Terracotta |
| **Slate** | Cool blue-grey | Steel blue |
| **Sage** | Green-tinted neutrals | Muted sage |
| **Iris** | Violet-tinted neutrals | Muted iris |

Each card in Settings shows the palette in miniature, light and dark side by side. Whatever the palette, the colours
that carry meaning stay the same — success, warnings and errors, the mastery stages, the graph's communities — and
all text and controls keep the contrast WCAG 2.2 AA asks for.

## Simplified UI

On unless you turn it off. It quietens the interface in the spirit of Obsidian; every button, menu and shortcut
stays where it can be found.

- **Fewer lines.** Where a change of background already separates two areas (a page's header and its content, a
  pane's header and its body, the tab row, a section's heading), the line between them goes; beside the sidebar and
  between two note panes it stays, fainter. Cards lose their border in the light themes (their white already stands
  out from the page) and keep a faint one in the dark.
- **Notes.** The Files and Details panes sit on the sidebar's surface, the note on the page's, as in Obsidian. The
  title row folds into the tab row (*Show files*, *New note* and *Show details* sit at its right end). When the note's
  pane is wide, the save status and word count move to its bottom-right corner; in a narrower pane they stay in the
  note's header, so they never cover the text. The editor has no band behind the current line.
- **The file list,** like Obsidian's: no icons (folders keep their arrow), compact rows, a faint guide line for each
  folder level, attachments with a small file-type tag (*PNG*, *PDF*), and the full path when you hover over a name.

Turn it off for the previous, more structured interface: dividers everywhere, icons in the file list, the title row
above the tabs. Switching back and forth changes nothing else.

In either interface, **Show files** / **Hide files** opens and closes the file list. It never narrows below the width
of its toolbar, and in a phone-sized window it starts closed so that the note has the room.

## Strict line breaks

Off unless you turn it on. Off is how Obsidian behaves: a single line break in a note is a line break in the reading
view. On follows standard Markdown, where only a blank line starts a new paragraph. It changes how notes are shown,
never the files.
