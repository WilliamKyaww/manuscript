## Implementation map

- `packages/core/src/api/file-preview.ts`: Zod preview response and authenticated preview endpoint contract.
- `apps/server/src/modules/notes/preview/service.ts`: contained vault-file reads, format dispatch, size/text
  caps, DOCX reuse, JSON/text/code handling and useful errors. `tables.ts`: quoted CSV and bounded OOXML XLSX
  sheets/shared strings/cached formula values. No spreadsheet formulas execute in Reading mode.
- `legacy-word.ts` / `file-preview-worker.mjs`: `word-extractor` 1.0.4 (MIT) extracts legacy binary DOC text
  in a worker with a 5-second timeout, 64 MB old-generation limit, OLE signature check and concurrency cap.
  `scripts/build-server.mjs` bundles the worker beside the server so packaged apps do not need source files.
- `preview/layout.ts`: a temporary copy converted to PDF by LibreOffice with a private profile, macros
  disabled, Writer link updates set to 2 (never), Calc to 1 (never), one conversion at a time, 45-second
  subprocess deadline and temporary-folder cleanup. Standard install locations or `SKB_LIBREOFFICE_PATH`.
- Notes `routes.ts`: `/api/file-preview?path=…` JSON and `/api/file-layout?path=…` PDF; existing vault
  containment and authentication remain in force. Originals are not edited.
- `apps/web/src/features/notes/files/FileTab.tsx` / `LayoutPreview.tsx`: read-only file header, Download,
  Refresh, Reading/Page layout/Source controls, PDF/image/text/code/document/table rendering and sheet selector.
  HTML uses a scriptless sandbox with restrictive CSP. SVG stays an image, never inline application DOM.
- `workspace-store.ts` adds persistent `filePath` tabs; `EditorPanes.tsx`, `useVaultActions.tsx`, `NotesPage.tsx`
  and `FilesPane.tsx` integrate selection and support attachment-only vaults. `FileEmbed.tsx` and
  `MarkdownPreview.tsx` open attachment links in file tabs.
- `library/viewer/pdfjs.ts` / `PdfViewer.tsx` accept PDF byte arrays as well as URLs and reset load/error
  state on a new document. Office PDF bytes are passed directly, cloned before PDF.js transfers them.
- Tests: `preview/preview.test.ts`, `preview/layout.test.ts`, `workspace/file-workspace.test.ts`,
  `e2e/file-previews.spec.ts`; generated complete Office fixtures in `test/fixtures/file-previews.ts`.
- Docs: ADR-0048, Phase 28 checklist, B-KM-38, F-KN-30, Markdown guide's File previews section, PRD knowledge
  system, third-party notices, STATE and journals.
